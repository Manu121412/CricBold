# CricBold
Cricket Scores and Highlights

## About
- Live cricket scores and match updates
- Key highlights from ongoing and recent matches
- Player and team performance tracking
- Fast, simple cricket insights for fans

## Requirements
- Python 3.9 or later
- Flask
- A web browser
- Internet connection for fetching cricket data
- Optional: VS Code or any text editor for development
